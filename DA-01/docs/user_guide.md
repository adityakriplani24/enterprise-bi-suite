# User Guide: Enterprise BI Suite (one page)

**Who this is for:** Executives and regional managers.  
**Where:** Power BI Service -> Workspace *Enterprise BI* -> report *Enterprise BI Suite*.

## What you see
You see only the regions assigned to you. Executives see everything. If a page is empty, you have no region assigned: contact the BI owner.

## Pages
| Page | Use it to |
|------|-----------|
| **Executive Overview** | Sales, Gross Profit, Margin %, YoY %, YTD vs last year, regional ranking |
| **Sales & Products** | Category/subcategory performance, top and bottom products, channel split |
| **Finance** | Actual vs Budget variance by account (executives only) |
| **Supply Chain** | Inventory units/value and days of inventory |
| **HR** | Headcount, rates, vacation hours by department |
| **Order Detail** (drill-through) | Right-click any region, product or month on an overview page -> **Drill through -> Order Detail** |

## How to use
1. Use the **Year / Quarter** slicers at the left to set the period.
2. Click any bar or map point to cross-filter the whole page; click again to clear.
3. Hover a visual and use **Focus mode** to enlarge it; **... -> Export data** for tables.
4. Use the **Back** button (top-left) after drilling through.

## Definitions
- **Gross Profit** = Sales - Product Cost. **Margin %** = Gross Profit / Sales.
- **YTD** = January 1 to the selected date. **YoY %** = change versus the same period last year.
- **3M Rolling Avg** = average monthly sales over the latest 3 months.

## Data freshness
Refreshed daily at 06:00 IST (see refresh history in the Service). Last refresh time is shown on the Overview footer.

## Support
Report issues to the BI owner with a screenshot and the filters applied.
