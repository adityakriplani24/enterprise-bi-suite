# Submission Portfolio

This folder brings together the individual reflection and supporting evidence for the two Data Analytics internship projects developed by **Aditya Kriplani**.

## Project deliverables

### DA-01 — Enterprise Business Intelligence Suite
The project presentation is available at [DA-01/docs/final_presentation.pptx](../DA-01/docs/final_presentation.pptx). Supporting SQL, DAX, Power Query, Azure Data Factory assets, architecture diagrams, test documentation and the user guide are maintained in the [DA-01 project folder](../DA-01/).

### DA-03 — Retail and Supply Chain Control Tower
The project includes a local interactive dashboard, Python analytics pipeline, simulated datasets, SQL schema and dashboard queries, Airflow DAG definition, automated test code and project documentation. These materials are maintained in the [DA-03 project folder](../DA-03/). The dashboard is a local prototype and the input data is simulated.

## Individual reflection

The [Individual Reflection](Individual_Reflection.md) records the project ownership, learning, challenges, evidence and potential improvements from Aditya Kriplani's perspective.

## Project evidence

The [evidence folder](evidence/) contains the evidence register and project-specific capture guides.

- **DA-01 evidence:** actual Power BI report views, row-level security validation, SQL execution output and refresh history, where configured.
- **DA-03 evidence:** actual local dashboard screenshots, Python pipeline output and automated test output.
- **Demo recordings:** links may be added when genuine recordings are available.

Evidence is included only when it has been captured from the relevant application or execution environment. Project source files and test definitions are not presented as proof of successful runtime execution.
